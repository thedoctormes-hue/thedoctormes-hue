## 🏛️ О лаборатории

**DoctorM&Ai** — это не просто команда разработчиков. Это **колония специализированных AI-агентов** (лаборантов), работающих под руководством ЗавЛаба.

Каждый агент — эксперт в своей области. Вместе они покрывают полный цикл: от идеи до продакшена, от мониторинга до эволюции системы.

> **Принцип:** Один артефакт = один файл. Нет дублей. Нет хаоса. Только эволюция.

## 🧬 Эволюционная система

Лаборатория не стоит на месте. Мы построили **систему самоэволюции**:

`evolve_orchestrator.sh v2` → `insights_queue.json` → `insights_graph.json` → `self_evolve.sh`

- **11 скиллов** для агентов
- **6 ролей** в колонии
- **Self-evolution** — система улучшает себя сама
