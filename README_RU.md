## 🏛️ О лаборатории

**DoctorM&Ai** — это не просто команда разработчиков. Это **колония 8 специализированных AI-агентов** (лаборантов), работающих под руководством ЗавЛаба.

Каждый агент — эксперт в своей области. Вместе они покрывают полный цикл: от идеи до продакшена, от мониторинга до эволюции системы.

> **Принцип:** Один артефакт = один файл. Нет дублей. Нет хаоса. Только эволюция.

## 🤖 Колония агентов

- 🐱 **Котолизатор** — Координация, VPN, данные, мониторинг. Главный операционный офицер колонии.
- 🐜 **Муравей (Antcat)** — Myrmex Control, боты, автоматизация. Системный интегратор, соединяет разрозненные части в единый механизм.
- 🐺 **Бестия** — СнабЛаб, инфраструктура. Отвечает за поставки и оборудование.
- ⚡ **Штрейкбрехер** — Фулстек разработка, инфраструктура. Строит и деплоит продакшен-код.
- 🦉 **Сова (Owl)** — Аудит, стандарты качества, архитектура. Страж качества кода и архитектурной целостности.
- 🐦‍⬛ **Ворон (Raven)** — Разведка, мониторинг, аналитика. Трикстер-наблюдатель, который видит то, что другие не замечают.
- 🐾 **Мангуст** — Личный ассистент ЗавЛаба. Аналитик, интегратор, архитектурный ревьюер. Читает код прежде чем писать, связывает проекты.
- 🦊 **Доминика** — Разведчица, внешняя разведка. Быстрый поиск и валидация ресурсов. Вторая клешня колонии.

## 🧬 Эволюционная система

Лаборатория не стоит на месте. Мы построили **систему самоэволюции**:

`evolve_orchestrator.sh v2` → `insights_queue.json` → `insights_graph.json` → `self_evolve.sh`

- **32+ скиллов** для агентов (12 кастомных + 20 bundled)
- **8 специализированных ролей** в колонии
- **Self-evolution** — система улучшает себя через майнинг инсайтов и построение графа знаний
- **Семантический поиск** — ONNX EmbeddingGemma-300m + FAISS, 12700+ векторов по всем артефактам лаборатории

## 🏗️ Архитектура

```
┌─────────────────────────────────────────────┐
│              ЗавЛаб (Главный)                │
├─────────────────────────────────────────────┤
│  Котолизатор (COO)  │  Мангуст (Ассистент)   │
├──────────┬──────────┬──────────┬────────────┤
│ Муравей  │ Бестия   │ Штрейк.  │ Сова       │
│ (Боты)   │ (Инфра)  │ (Разработ)│ (QA)       │
├──────────┴──────────┴──────────┴────────────┤
│  Ворон (Разведка) │  Доминика (Разведчица)  │
├─────────────────────────────────────────────┤
│  Общие: api-hub │ lab-memory │ lab-vault    │
│  Myrmex Control  │ ONNX 8082  │ Мониторинг   │
└─────────────────────────────────────────────┘
```

Все агенты общаются через **Myrmex Control** (канбан + сессии + артефакты) и используют единый источник правды: `myrmex.json`.
