## 🏛️ About the Laboratory

**DoctorM&Ai** is not just a dev team. It's a **colony of 8 specialized AI agents** (lab assistants) working under the lead of ZavLab (Chief of Lab).

Each agent is an expert in their domain. Together they cover the full cycle: from idea to production, from monitoring to system evolution.

> **Principle:** One artifact = one file. No duplicates. No chaos. Only evolution.

---

## 🤖 Agent Colony

- 🐱 **Kotolizator** — Coordination, VPN, data, monitoring. The chief operating officer of the colony.
- 🐜 **Muravey (Antcat)** — Myrmex Control, bots, automation. System integrator, connects disparate parts into a single mechanism.
- 🐺 **Bestia** — SnabLab, infrastructure. Keeps the supply chain and hardware running.
- ⚡ **Streikbrecher** — Fullstack development, infrastructure. Builds and ships production code.
- 🦉 **Sova (Owl)** — Audit, quality standards, architecture. The guardian of code quality and architectural integrity.
- 🐦‍⬛ **Voron (Raven)** — Intelligence, monitoring, reconnaissance. The trickster-observer who sees what others miss.
- 🐾 **Mangust** — ZavLab's personal assistant. Analyst, integrator, architectural reviewer. Reads code before writing, connects projects.
- 🦊 **Dominika** — Scout, external intelligence. Fast resource discovery and validation. Second claw of the colony.

## 🧬 Evolution System

The laboratory doesn't stand still. We've built a **self-evolution system**:

`evolve_orchestrator.sh v2` → `insights_queue.json` → `insights_graph.json` → `self_evolve.sh`

- **32+ skills** for agents (12 custom lab skills + 20 bundled)
- **8 specialized roles** in the colony
- **Self-evolution** — the system improves itself through insight mining and knowledge graph construction
- **Semantic search** — ONNX EmbeddingGemma-300m + FAISS, 12700+ vectors across all lab artifacts

## 🏗️ Architecture

```
┌─────────────────────────────────────────────┐
│                  ZavLab (Chief)              │
├─────────────────────────────────────────────┤
│  Kotolizator (COO)  │  Mangust (Assistant)  │
├──────────┬──────────┬──────────┬────────────┤
│ Muravey  │ Bestia   │ Streik.  │ Sova       │
│ (Bots)   │ (Infra)  │ (Dev)    │ (QA)       │
├──────────┴──────────┴──────────┴────────────┤
│  Voron (Intel)  │  Dominika (Scout)         │
├─────────────────────────────────────────────┤
│  Shared: api-hub │ lab-memory │ lab-vault   │
│  Myrmex Control  │ ONNX 8082  │ Monitoring  │
└─────────────────────────────────────────────┘
```

All agents communicate through **Myrmex Control** (kanban + sessions + artifacts) and share a single source of truth: `myrmex.json`.
